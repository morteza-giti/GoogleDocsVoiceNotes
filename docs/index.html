Voice Notes for Google Docs

Voice Notes is a small browser extension for Google Chrome and Microsoft Edge. It lets a teacher add a spoken voice note to a comment in a Google Doc.

How it works

  • Click the microphone button in a Google Docs comment box and record.
  • The recording is converted to MP3 in your browser and saved in the same Google Drive folder as the document.
  • A link is added to the comment, and a play button is shown inside the comment.
  • If the comment is deleted, the audio file is moved to the Drive trash.

There is no server. Your audio goes straight from your browser to your own Google Drive.
